# VEH Debugger v1.1.17

## Added

- Added bounded targeted input-matrix capture with per-input checkpoint setup, occurrence-triggered pre/post trace windows, environment snapshots, and no-overwrite JSON artifacts.
- Added function-scoped tracing that follows external calls and stops only when the original frame returns.
- Added token-bounded MCP exposure profiles and the lazy `veh_toolbox` gateway while preserving direct calls for existing automation.

## Changed

- MCP documentation now treats the running server's `tools/list` response as the authoritative inventory instead of relying on brittle hard-coded counts.

## Fixed

- Repeated checkpoint-based captures preserve live VEH stack frames, reject exception and zero-step results, and correctly step through restored entry breakpoints.
- Trace startup skips inaccessible image gaps, and long trace requests no longer self-cancel at the heartbeat boundary.
- Large trace responses retain actionable transport and collector diagnostics instead of failing opaquely.
- Runtime code is captured from executed edge destinations, avoiding false completeness failures from unexecuted synthetic block prefixes.
- Memory-form NOP padding no longer produces false unsupported-read events.
